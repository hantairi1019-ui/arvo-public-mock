独立モック
公開ページからはAPIを直接呼び出せません

GitHub Pagesは画面の静的配信のみのため、APIキーを保護してJ-Quants APIを呼び出す中継機能がありません。実行するには下記2ファイルを同じフォルダーに保存し、Pythonでローカルサーバーを起動してください。

  1. 画面ファイル api-service.html と 中継サーバー api-service-server.py を同じフォルダーに保存
  2. そのフォルダーで py api-service-server.py を実行
  3. http://127.0.0.1:8765/ を開いてAPIを実行

APIキーはローカルサーバーからJ-Quantsへ送信され、ファイルやログには保存しません。
